# Synthetic graph generator

`generate_zipfian_graph.py` produces the `bench_vertices` / `bench_edges` table
pair used by `BenchmarkConnectedComponents.java`. For each named scale the
generator builds a power-law-skewed directed graph by inverse-CDF sampling of
endpoint ids:

    rank = floor(N * U^alpha) + 1,   U ~ Uniform(0,1)

This is a faithful reproduction of the *shape* of the inputs used in the
paper's Section 12.5 hyperscale runs (Zipfian / power-law degree
distribution) but the random seed is not fixed; numbers will be similar in
character to but not identical to the original runs.

## Usage

```
export OCIENT_JDBC_URL="jdbc:ocient://<sql-node>:4050/<db>"
export OCIENT_USER="<user>"
export OCIENT_PASSWORD="<pw>"

python generate_zipfian_graph.py --scale wcc1b
```

`--scale` is one of `wcc100m`, `wcc1b`, `wcc10b`, `wcc100b`, `wcc1t`. Use
`--dry-run` to print the dataflow SQL without executing it.

The wrapper relies on `sys.dummy*` virtual row sources to build sufficiently
large iterators; trillion-edge generation requires `sys.dummy100000000000`
(10^11). Smaller clusters may not have that view — adjust `cross_dummy()` in
the script to compose two smaller `sys.dummy*` views via `CROSS JOIN` if
needed.

## What it does NOT preserve

- Random seed: the original 1T-edge graph used in the paper was generated by
  a separate dataflow that wasn't preserved as a clean reusable artifact.
  This wrapper substitutes an equivalent generator with the same table
  structure and similar power-law character; the WCC results will be
  qualitatively similar but not bit-identical.
- Strict Zipfian sampling. Inverse-CDF on `U^alpha` is a power-law
  approximation, not a true Zipf draw. For benchmark reproduction the
  observable effects (heavy-tailed supernodes; long tail of low-degree
  vertices) match what the paper reports.
